# Deployment checklist

1. Create a new public GitHub repository.
2. Upload `app.py`, `requirements.txt`, `README.md`, `reports/`, and `src/`.
3. Open Streamlit Community Cloud and create a new app from the repository.
4. Select `app.py` as the main file.
5. Deploy and test all five tabs.
6. Copy the final Streamlit URL into the Unified Mentor submission form.
7. Record the short feedback video using `reports/video_feedback_script.md`.
8. Upload the video to a service that provides a shareable HTTPS URL, then paste that URL into the form.
9. For the Research Paper field, use the public URL of the PDF after placing it in the GitHub repository (or another approved public document host).
